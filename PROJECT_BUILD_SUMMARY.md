## 🚀 Quick Start Guide

### Backend Setup

```bash
cd backend
npm install
cp .env.example .env
# Update .env with MongoDB URI, JWT secret, etc.
npm run dev
# Server runs on http://localhost:5000
```

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
# App runs on http://localhost:5173
```
